# Прямоугольная фотография на голове

По просьбе пользователя проекция на скелетную сетку полностью заменена отдельным прямоугольником с ранее присланным фото (кадрировано лицо). Фотография находится перед лицом и следует положению/повороту головы, не смотрит постоянно на камеру. Текстура выводится без изменения освещением. Пропорции фото сохранены, ширина 22 см; размер не зависит от масштаба FBX-костей.

Остановите Play → распакуйте DonsportRectangularPhoto.zip в корень проекта с заменой → дождитесь импорта и компиляции → запустите заново. На уже установленной сцене Донспорта повторная настройка не нужна: используется существующий DonsportPhotoFace и материал с тем же шейдером. Не накладывайте старые ZIP поверх этого патча. Фото в Resources включено как резерв при отсутствии сериализованной ссылки. Если компонент/материал отсутствуют, сначала установите предыдущий DonsportGymFaceFix.

Старая проекция больше не создаётся, эллиптической маски нет. ZTest LEqual и запись глубины включены, поэтому стены закрывают фото. Коллайдеров у фотографии нет. При отключении персонажа/компонента фото скрывается, при уничтожении объекта удаляются фото, собственные mesh и материал. Тренировки посетителей, речь и задания не меняются.

Это намеренно плоская прямоугольная накладка: сбоку видна плоскость, сзади фотография может читаться зеркально (двусторонняя отрисовка). Исходная голова и волосы не вырезаются из общей сетки модели. Если фото пересекается с носом/чёлкой, для подгонки есть photoWidth, forwardOffset и verticalOffset на DonsportPhotoFace; пришлите скриншот — можно скорректировать значения патчем.

Проверены синтаксис C#, обычные UV, наличие текстуры, глубина и ZIP. Unity здесь недоступна: фактическую посадку на конкретной голове нужно проверить в игре.
