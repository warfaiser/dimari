# Исправление TextureImporter фото для Unity 6

На пользовательском скриншоте Unity сообщает, что DonsportMaybeBabyFace.png.meta содержит TextureImporter версии 1, ниже поддерживаемого минимума 10. PNG не загружается, поэтому создание головы останавливается. Поставленные ранее метаданные содержали только fileFormatVersion/guid без явного блока TextureImporter — это дефект архива.

Исправлены обе копии портрета: Resources/DonsportMaybeBabyFace.png и Art/DonsportStory/MaybeBabyFace.png. Их .meta теперь содержат явный TextureImporter serializedVersion 12 (это версия импортера, не fileFormatVersion). GUID сохранены. Установщик также проверяет именно эти два .meta перед импортом и при некорректной версии восстанавливает блок, сохраняя GUID текущего проекта. Остальные .meta и ассеты не меняются.

## Установка

1. Остановите Play.
2. Распакуйте DonsportTextureImporterFix.zip в корень проекта **с заменой файлов, включая два .png.meta**. Папки не удаляйте.
3. Дождитесь импорта/компиляции. Если в Console остаются прежние сообщения, Clear очистит старые записи — это не исправление само по себе.
4. В открытой Chapter2_Rogovo выполните **Dimari → Донспорт — создать голову с фото прямо в Scene**.
5. Если коробка появилась и выделена — Ctrl+S вне Play. Если снова ошибка, пришлите только новые сообщения после этой команды.

Если прежние .meta были сохранены при распаковке, команда сама пытается исправить их перед принудительным синхронным импортом фото. Назначение фото материалу выполняется по пути, а не по старой сломанной ссылке. Внешний вид коробки, тренировки и задания не переработаны.

Проверены C# синтаксис, версии обоих импортеров, неизменность GUID и содержимое архивов. Unity 6 здесь нет: фактический импорт и создание коробки требуют подтверждения в проекте пользователя.
