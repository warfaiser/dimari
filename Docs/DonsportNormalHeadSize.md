# Обычный размер головы с фото

Фото уже импортируется и видно. Этот патч только уменьшает голову-коробку с 44×50×44 до 23×28×24 см. Ограничение минимального размера 38×44×38 см убрано. Старые сохранённые boxSize также обновляются однократной миграцией, а не только сменой значения по умолчанию в коде.

Остановите Play → распакуйте DonsportNormalHeadSize.zip в корень проекта с заменой → дождитесь компиляции → в Chapter2_Rogovo выполните **Dimari → Донспорт — создать голову с фото прямо в Scene** → Ctrl+S. Команда заменяет только существующую коробку, сохраняя персонажа и задания. При открытии сцены обновление старого размера также применяется автоматически. В игре размер не возвращается к прежнему большому.

Размер в метрах, позиция/фото/материалы/импортёр не меняются. Исходная голова не вырезается из общей скелетной сетки: при уменьшении край волос может выступать, это нужно оценить на конкретном риге. Ручные значения boxSize после этой однократной миграции не сбрасываются. Проверены C# синтаксис, согласованность размеров редактора/игры, миграция и ZIP. Unity здесь не запускалась.
