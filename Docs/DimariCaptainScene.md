# Корабль, капитан, вода и плавание к Рогово

## Главное: вернули настоящий корабль

Встроенный корабль (баржа с белой рубкой и одним парусом) строился потому, что в предыдущей версии стоял флаг `useProceduralShip = true`, и поиск моделей вообще не выполнялся.

Теперь:

1. Сначала используется **префаб из поля Ship Prefab**.
2. Если поле пустое или там заглушка — **поиск по ассетам проекта** (`pirate`, `ship`, `galleon`, `vessel`…), как в первой рабочей версии.
3. Встроенный корабль строится только если настоящая модель не найдена.

Старое поле `useProceduralShip` больше ни на что не влияет, даже если в сцене сохранено значение `1`: его читает только новый флаг `forceBuiltInShip` (по умолчанию выключен).

В Console видно источник модели:

- `Корабль: префаб из поля Ship Prefab — <имя>` — взята назначенная модель;
- `Загружен 3D-корабль из ассета: <путь>` — модель найдена автоматически;
- `Корабль из ассетов не найден. Строю встроенный корабль…` — модели нет, назначьте её в Ship Prefab.

## Заглушка StylShip_Box

`StylShip_Box` (39.6 × 19.8 × 39.6) — ящик-коллайдер из набора. Он отклоняется по имени меша и по форме: в плане почти квадрат, высота больше длины. Проверка выполняется и для поля Ship Prefab, и для найденных ассетов. Заглушка больше не может стать кораблём.

Если ящик уже сохранён в сцене: меню **Dimari → «Корабль — убрать заглушку StylShip_Box из сцены»**, затем Ctrl+S.

Низкополигональные настоящие корабли не отбрасываются: отсекается только примитив (меньше 80 треугольников и квадратный план).

## Метка обрыва

Маркер `cliffArrivalPoint` больше **не поворачивается** автоматически. Он остаётся там, где вы его поставили; вдоль его forward строятся вода, причал и точка разговора. Корабль ставится по `Ship Offset From Cliff`; если точка попала на сушу, он сдвигается не дальше 45 м до ближайшей воды (в Console — `Точка корабля по смещению была не на воде…`).

## Капитан и камера

- Штурвал ищется до установки капитана; из нескольких штурвалов выбирается тот, над которым открытое небо (декоративный штурвал в каюте проигрывает).
- Капитан ставится за штурвал на измеренную палубу, человеческий масштаб.
- Если расчётная точка попала в закрытое помещение, капитан и герой переносятся на ближайшую открытую палубу.
- Камера разговора — боковой двухплан с 1.45 м (рюкзак героя не закрывает кадр).

## Плавание к Рогово

Если строгий морской коридор не найден, используется простой морской маршрут: `Строгий коридор не найден; используется простой морской маршрут…`. Плавание не отменяется молча, после него загружается глава 2.

## Порядок установки

1. Остановить Play.
2. Распаковать DimariCaptainFix.zip в корень проекта с заменой.
3. Дождаться компиляции.
4. Дойти до обрыва и проверить Console.

Проверено статически (синтаксис, повторные члены, локальные дубликаты, состав архива). Unity в песочнице нет — фактические точки видны в Console.
