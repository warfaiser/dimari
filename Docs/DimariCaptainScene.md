# Почему вместо корабля была коробка и что исправлено

## Причина (видна в вашем Console)

```
[Dimari] Загружен 3D-корабль из ассета: Assets/Stylized_Pirate_Ship/StylShip_Box.prefab
[Dimari] Корабль измерен: палуба на 19.75 м (локально), габариты (39.6, 19.8, 39.6)
```

Игра брала **StylShip_Box** — служебную коробку-заглушку из пака Stylized Pirate Ship (прямоугольный коллайдер/бокс), а не сам корабль. Автоподбор смотрел только на слово «ship» в пути и не проверял форму. Размеры 39.6 × 19.8 × 39.6 — это куб, и капитан оказывался на его крышке на высоте 19.75 м. Отсюда «коричневая стена» и кат-сцена на краю карты.

## Что исправлено

1. Заглушки исключены по имени: `box`, `collider`, `collision`, `proxy`, `trigger`, `volume`, `bounds`, `outline`, `lod`, `pivot`, `anchor`, `socket`, `empty`, `dummy`.
2. Добавлена проверка формы каждого кандидата: корпус должен быть длиннее, чем шире (в плане не квадрат), высота не больше длины, и это не одна простая деталь. `LooksLikeShip` отклоняет куб 39.6 × 19.8 × 39.6 и пишет причину в Console.
3. Если подходящего префаба нет, строится **встроенный процедурный корабль** — с корпусом, палубой, рубкой, мачтой и парусом.
4. У процедурного корабля появился маркер палубы `ShipBoardingPoint` (1.16 м): капитан, герой и подъём из воды ставятся по нему, без угадывания.
5. Если палуба измеряется, она не может быть выше 85% корпуса — крышка коробки больше не считается палубой.
6. Камера кат-сцены: широкий план плавания считается от реальных габаритов; при разговоре — через плечо с проверкой перекрытий.
7. Новый переключатель **Use Procedural Ship** в компоненте StoryQuestManager: включает встроенный корабль и игнорирует импортированные префабы.

## Порядок

1. Остановить Play → распаковать DimariCaptainFix.zip в корень проекта с заменой → дождаться компиляции.
2. (Необязательно) Выделить `Dimari_GameSystems` → в инспекторе StoryQuestManager включить **Use Procedural Ship**, если хотите гарантированно встроенный корабль.
3. Play. В Console ожидается одно из:
   - `Загружен 3D-корабль из ассета: …` (уже не Box) — с проверкой формы;
   - `Корабль пропущен: …StylShip_Box.prefab — в плане почти квадрат…` и затем процедурный корабль;
   - `Палуба задана явно: 1.16 м …` — для процедурного.
4. F9 у капитана: `над палубой ≈ 0.0 м`.

Если понадобится вернуть конкретный корабль — есть поле Ship Prefab: перетащите туда нужный префаб, он используется без автоподбора.

Проверено статически: синтаксис C#, повторные члены, локальные дубликаты, состав архива. В Unity не запускалось; какие именно префабы есть в вашем проекте, покажет Console после Play — пришлите строки `[Dimari] Корабль пропущен…` и `Загружен 3D-корабль…`.
