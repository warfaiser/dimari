# Донспорт: Елизавета → поиск Мэйби Бэйби

## Установка

1. Остановите Play. Распакуйте DonsportStory.zip в корень проекта с заменой файлов, дождитесь компиляции и импорта аудио/текстуры.
2. Откройте **Chapter2_Rogovo** в редакторе. Существующий Донспорт не пересоздаётся и не перемещается. Установка запускается автоматически при открытии сцены; можно выполнить **Dimari → Донспорт — Елизавета и поиск Мэйби Бэйби**. Сохраните Ctrl+S вне Play.
3. Нужны ранее установленный DonsportSetup/CityLifeSetup и реальные импортированные Humanoid NPC. Без ресепшионистки/подходящей модели или свободного места команда ничего не подменяет примитивами; смотрите Console. Продавец пиццерии/Обжорка не переносится.
4. После пиццерии, с активной задачей city_donsport, войдите в клуб и подойдите к сотруднице за стойкой. Нажмите **E — Поговорить с Елизаветой**.

## Сцена

Шесть реплик пользователя сохранены дословно в DonsportReceptionCutscene.Lines. Все шесть озвучены выбранными мужским/женским голосами (Voice_Donsport_0…5). Для произношения в записи BMW 3 серии 320d / Changan Uni V прочитаны словами; в субтитрах осталось исходное написание. При отсутствующем аудио работает время на чтение, не чужая реплика.

Камера чередует героя и Елизавету, герой временно не управляется; при открытии меню речь и таймер ждут возврата. После сцены восстанавливаются камера/FOV, видимость героя и управление. При отключении/пропаже актёра освобождение без завершения задания. F5 во время разговора отклоняется; после него сохраняется этап.

Для повторного просмотра: в Play у стойки **Dimari → Донспорт — повторить разговор Елизаветы (Play, у стойки)**. Задание не дублируется.

После последней фразы завершается city_donsport и появляется city_maybe_baby: найти Мэйби Бэйби среди людей в тренажёрном зале. Герой сам проходит через существующий проход справа (локально x≈7.1,z≈2.05), без телепорта и без прокладывания пути сквозь мебель. В зале создаётся до девяти тихих стоящих посетителей на свободных поддерживаемых точках, без перестройки улиц. Если точек нет, установка откатывается. У Мэйби Бэйби маркер появляется только внутри зала при прямой видимости; у стен он не рисуется. При подходе ближе 3 м с видимостью задача поиска завершается. Реплик/следующей истории певицы нет: пользователь пока их не задавал.

Сохранение/загрузка восстанавливает задачу поиска через сохранённое завершение city_donsport и city_maybe_baby. При новом старте прогресс не берётся из старого сейва.

## Внешность по фото — ограничение

В архиве есть обрезанная текстура лица из приложенного пользователем фото. Она проецируется **на поверхность существующей скелетной головы**, а не на прямоугольник перед персонажем: DonsportPhotoFace + PhotoFaceDepth.shader. Есть проверка глубины, через стены лицо не рисуется. Добавлен светлый аксессуар-ободок. Основа выбирается из уже импортированных женских Humanoid по имени префаба, иначе из существующей ресепшионистки; новые платные/сторонние модели не добавлены.

Это **прототип совмещения фото с чужой геометрией, а не гарантированно похожая полноценная 3D-модель**. Положение глаз/профиль, волосы, UV/материал и размер головы зависят от импортированного NPC. В Unity здесь это не проверено. После установки нужен скриншот лица спереди и сбоку для подгонки; если проекция не подходит конкретной голове, компонент DonsportPhotoFace можно отключить. Все обычные посетители без фото. Голос певицы не клонируется и её речь не генерируется.

## Проверки

Синтаксис C#, шесть WAV, порядок актёров, сохранение этапа и содержимое ZIP проверены статически. Unity/URP, сцены и модели пользователя недоступны: компиляция Unity, шейдер на конкретной платформе, кадры у мониторов/колонны, посадка текстуры лица, свободный проход и фактическое число посетителей требуют проверки в полном проекте.
